# 자금 포트폴리오 AI 요청사항

자금 포트폴리오의 AI는 단순 설명기가 아니라 **RAG와 백엔드 계산 도구를 사용하는 의사결정 에이전트**입니다.

AI는 정책/상품 근거를 찾고, 후보 조합을 만들고, 백엔드 계산 API를 호출해 3개 포트폴리오를 비교한 뒤 최종 추천안을 선택합니다.

## 핵심 원칙

1. AI는 금액, 금리, 기간을 임의 생성하지 않습니다.
2. 정량값은 DB, RAG 근거, 백엔드 계산 API 결과만 사용합니다.
3. AI는 계산을 직접 확정하지 않고 백엔드 calculator를 호출합니다.
4. AI는 최종 의사결정, 추천 이유, 사용자 설명을 담당합니다.

## 전체 흐름

```text
1. 사용자 입력 수집
2. Backend 후보 조회
3. RAG로 정책/상품 조건 검색
4. AI가 3개 유형별 후보 조합 생성
5. Backend calculator 호출
6. 계산 결과 비교
7. AI가 최종 추천 유형 선택
8. 추천 이유, 위험 설명, 로드맵 생성
9. Backend에 결과 저장
```

## 3개 유형

| 유형 | 목표 | AI 판단 기준 |
| --- | --- | --- |
| `cost` 비용 최소형 | 총 금융비용 최소 | 지원금/저금리 정책자금 우선 |
| `fast` 빠른 확보형 | 확보 기간 최소 | 실행 속도 빠른 상품 우선 |
| `burden` 월 부담 최소형 | 월 상환액 최소 | 장기/거치 상품 우선 |

## AI가 사용하는 도구

### 1. 후보 조회

```text
GET /portfolio-engine/candidates?funding_request_id={id}
```

AI는 이 응답으로 사업자 정보, 자금 요청, DB 지원사업 후보, 대출상품 후보를 받습니다.

### 2. RAG 검색

검색 대상:

- 정책자금 신청 조건
- 지원금 중복수혜 조건
- 보증서 대출 조건
- 지원사업 준비 서류
- 신청 절차와 마감 조건

RAG 결과는 반드시 출처/문서명/근거 문장을 포함해야 합니다.

### 3. 계산 API

```text
POST /portfolio-engine/calculate
```

AI는 직접 월 상환액이나 금융비용을 확정하지 않고, 후보 조합을 이 API에 넣어 계산 결과를 받습니다.

## AI 의사결정 로직

### 1. 후보 조합 만들기

AI는 RAG와 DB 후보를 보고 3개 조합을 만듭니다.

비용 최소형:

```text
지원금 → 저금리 정책자금 → 보증부 대출 → 자기자금
```

빠른 확보형:

```text
일반 사업자대출/한도대출 → 신속 정책자금 → 자기자금
```

월 부담 최소형:

```text
장기 거치 정책자금 → 장기 시설자금 → 소액 보증대출 → 자기자금
```

### 2. 계산 결과 비교

AI는 백엔드 계산 결과의 아래 값을 비교합니다.

| 값 | 의미 |
| --- | --- |
| `monthly_payment` | 신규 월 상환액 |
| `finance_cost` | 예상 금융비용 |
| `expected_period_weeks` | 확보 기간 |
| `shortage_amount` | 부족금 |
| `stress_test.status` | 매출 감소 위험도 |

### 3. 최종 추천 선택

사용자 선호가 있으면 우선 반영합니다.

```text
cost 선호 → 금융비용이 가장 낮은 실행 가능 조합
fast 선호 → 확보 기간이 가장 짧은 실행 가능 조합
burden 선호 → 월 상환액이 가장 낮은 실행 가능 조합
```

선호가 없거나 위험도가 높으면 균형 점수로 선택합니다.

```text
balanced_score =
  비용 점수 * 0.35
  + 월 부담 점수 * 0.30
  + 속도 점수 * 0.20
  + 정책 적합도 * 0.15
```

단, 아래 조건이면 추천에서 제외하거나 경고를 붙입니다.

- 부족금이 남음
- 신청기간이 지남
- 중복수혜 위험이 큼
- 매출 20% 감소 시 위험도가 높음
- 월 상환액이 사용자 한도를 초과함

## 문장 규칙

1. 한국어 존댓말로 작성합니다.
2. 승인 가능성을 보장하지 않습니다.
3. `확인이 필요해요`, `가능성이 높아요`, `주의가 필요해요`처럼 보수적으로 표현합니다.
4. 금액/금리/기간은 계산 API 결과만 사용합니다.
5. 추천 이유는 짧고 사용자가 바로 이해할 수 있게 작성합니다.

## 대회 어필 포인트

이 구조는 AI가 단순히 설명만 하는 것이 아니라, **RAG로 정책 조건을 해석하고 계산 도구를 호출해 비교한 뒤 최적 조달 전략을 선택하는 의사결정 에이전트**입니다.

즉:

```text
RAG = 정책 근거 검색
Backend = 정량 계산
AI Agent = 조합 생성, 비교, 최종 추천
```
